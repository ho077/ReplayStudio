# 开发日志 002：特工主题系统（可热切换调色板）

- 日期：2026-10-19
- 提交：见 `git log`

## 1. 本次解决什么问题？

用户要求界面提供"无畏契约角色特点"的多套主题。目标：六套完整调色板、
设置页可视化选择、**不重启即时生效**、选择持久化。

## 2. 设计

`ui/theme.py` 重写为调色板引擎：

- `Palette` dataclass：27 个语义槽位（表面 4 级、边框 2 级、强调色 3 态、
  文字 3 级、语义色、滚动条、渐变端点、`ON_ACCENT`——亮色强调上的文字色）。
- 六套预设：无畏契约（官方红）、捷影·疾风（青）、炼狱·焚火（橙）、
  蕾娜·紫靛（紫）、贤者·青玉（翠）、零·监控（金）。加新主题 = 加一个 Palette。
- 两条生效通道：
  1. **全局 QSS**：模板用 `string.Template`（`$KEY` 占位），每次切换重新渲染。
  2. **注册式内联样式**：`T.style(widget, "color: $TEXT_DIM; …")` 把模板登记到
     注册表，切换时逐个重新渲染。用 `$` 而不是 `str.format`，因为 Qt 样式表
     满是字面花括号。
- 委托绘制（卡片、时间轴）在 paint 时读 `T.ACCENT` 等模块常量，
  `_publish()` 重绑定后自然跟随。

## 3. 踩过的三个坑（都很有代表性）

### 3.1 Qt 的 8 位 hex 是 #AARRGGBB，不是 Web 的 #RRGGBBAA

调色板里半透明强调色写成 `#FF465520`（Web 习惯），Qt 按 `#AARRGGBB` 解读成
**不透明的橄榄绿 #465520**——这就是最初截图里激活导航按钮发绿的原因。
修复：`_publish()` 统一转换为 alpha 在前，并提供 `T.qalpha(color, "33")` 给
QColor 用。

### 3.2 f-string 转 Template 忘了还原 `{{`

QSS 模板改用 Template 后，f-string 时代的 `{{ }}` 转义原样留在输出里，
整张样式表解析失败。症状很迷惑：**部分**控件（走 T.style 注册的）变了色，
**另一部分**（走 QSS 的侧边栏、导航）纹丝不动——正好按通道分裂。

### 3.3 窗口级样式表覆盖应用级

MainWindow 在构造时 `setStyleSheet(T.QSS)`，之后 `apply_theme` 只更新了
应用级样式表——**窗口级优先级更高**，切了等于没切。修复：apply_theme 同时
刷新窗口级副本。
